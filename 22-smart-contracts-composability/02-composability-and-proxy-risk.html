Stage 1 · 30 秒直觉对比

你存入了一个“经过 3 家顶级机构审计”的 DeFi 收益金库，半年后却被项目方瞬间卷走全部本金

代码不是说“上链后不可篡改”吗？项目方是怎么绕过审计把代码换掉的？
你存钱的合约只是一个“空壳转发器（Proxy）”！
为了方便修 Bug，许多项目采用 代理模式（Proxy Pattern）：用户的钱存在 Proxy 壳子里，但执行逻辑指向另一个 Implementation v1 合约。
如果管理员（Admin）权限握在项目方单个私钥手里且没有时间锁（Timelock），他只需 1 笔交易把指针切换到恶意的 Implementation v2（drainAll），就能合法转空所有用户的存款！
Stage 2 · 第一性原理拆解

无许可可组合性（Money Legos） vs 管理员升级权限

公链上所有协议共享同一本状态账本，任何合约都能无需审批直接调用另一个合约（就像乐高积木一样拼接出闪电贷、聚合器、循环贷）：

1 笔原子交易 = 质押 ETH(Lido) → 抵押 stETH 借 USDC(Aave) → 兑换资产(Uniswap)
安全治理铁律：不可升级（Immutable） > 多签 + 48h 时间锁（Timelock） >> 单签随时可升级（极高危）

Stage 4 · 链上真实档案与防坑

投研大额存钱前，30 秒排查“是否会被暗中换代码”

实战排雷三连问：
1. 在 Etherscan 上看合约页面是否出现 Read / Write as Proxy 标签（说明它是可升级代理合约）。
2. 如果是可升级合约，查看它的 Admin / Owner 地址是单个普通钱包，还是多签钱包 + 至少 24–48 小时 Timelock（时间锁）？
3. 链上乐高越叠越多（如协议 A 套协议 B 再套协议 C），风险不是相加而是木桶效应：只要最脆弱的一块乐高被黑，整串组合都会连锁受损。
