Stage 2 · 第一性原理拆解

Web3 协议估值的 3 把核心标尺

• P/F（全稀释估值 / 年化手续费收入）：类似股市市销率（P/S）。头部印钞机协议（如 Uniswap / Aave / Hyperliquid）的 P/F 通常在 5x ~ 30x；而空气项目往往高达 500x 甚至无穷大。
• MCap / TVL：衡量协议市值相对锁仓资金的溢价倍数（DeFi 协议一般 < 0.5 偏低估，> 2 偏泡沫）。
• 流通率（MCap / FDV）：衡量未来抛压大小（越高越安全）。

P/F 估值倍数 = FDV / 年化协议真实收入   |   资金效率 = 年化收入 / TVL
